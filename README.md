# 火依极客 AI机器人顾问系统

## 项目简介

火依极客（FireOne Geek）是一款基于大语言模型与机器人知识库构建的 AI机器人设计顾问系统。

它能够帮助用户从一个机器人想法开始，完成：

- 机器人方案设计
- 硬件选型
- AI架构规划
- 成本预算分析
- 制作路线规划

让没有专业机器人经验的用户，也能够快速理解并开始制作自己的AI机器人。

---

## 项目背景

目前机器人开发存在几个问题：

1. 硬件选择复杂
2. AI接入门槛高
3. 制作路线不清晰
4. 初学者不知道如何开始

火依极客希望通过AI顾问降低机器人开发门槛。
